# Focus Forest — Screenshot Baseline Review

## Observed strengths

The New Tab already communicates the product thesis well: the seed illustration, generous cream space, layered green clearing, serif mission prompt, restrained brand line, and single planting action form a calm entrance. The mission input and primary action have a clear visual hierarchy.

The page companion is present and functional, but its current form reads as a small utility badge rather than a living part of the same habitat. It needs a more deliberate leaf marker, better spacing, stronger state hierarchy, and a calm branch cue that remains subtle on dense pages.

## Priorities

| Priority | Refinement |
|---|---|
| High | Make the dashboard tree unmistakably structural: trunk/root, curved branches, leaf nodes, selected branch detail, resting garden state. |
| High | Make pruned, composted, neutral, and deep paths understandable without color alone. |
| Medium | Give the page companion a compact habitat identity while keeping it lightweight and non-intrusive. |
| Medium | Make the companion responsive on dense pages and narrow viewports without covering important page controls. |
| Required guardrail | Preserve the existing New Tab atmosphere instead of adding more decoration to the entrance. |
| Required guardrail | Keep tree motion event-driven through CSS/SVG transitions only; no loops, Canvas, images, or page-level tree. |

## Exclusions

The screenshot review does not justify a new framework, remote assets, sound, full-page overlay, continuous animation, AI, page-content reading, or a redesign of the New Tab hierarchy. The next work should improve the garden and companion while preserving the successful planting ritual.
